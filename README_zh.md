# Duix Skills

中文 | [English](README.md)

这是一个面向 AI Agent 的 [Duix](https://www.duix.com/) Skill 集合。每个 Skill 提供一个聚焦的工作流，并包含独立的安装与使用说明。

## Skills

| Skill | 功能简介 |
| --- | --- |
| [duix-avatar-video-generation](duix-avatar-video-generation/README_zh.md) | 输入人物视频和人声音频，生成对口型数字人口播视频；包含素材校验、积分确认、任务创建、状态轮询及输出文件处理。 |
| [duix-avatar-conversation](duix-avatar-conversation/README_zh.md) | 基于人像、音色和可选人设配置创建实时对话数字人，并返回可在浏览器中打开的对话链接。 |

## 快速开始

1. 从上方选择需要的 Skill，并打开其说明文档。
2. 将对应的 Skill 目录放入 AI Agent 的 skills 目录。
3. 按该 Skill 的说明完成 `duix-cli` 安装和凭证配置。

## 兼容性

本仓库的 Skills 面向支持 `SKILL.md` 的 Agent 环境设计，包括 Codex、Cursor、Claude Code、Copilot、Gemini 和 OpenClaw。具体兼容性及前置条件请以各 Skill 的 README 为准。
