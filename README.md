# Duix Skills

[中文](README_zh.md) | English

An open collection of [Duix](https://www.duix.com/) skills for AI agents. Each skill provides a focused workflow and its own installation and usage guide.

## Skills

| Skill | Description |
| --- | --- |
| [duix-avatar-video-generation](duix-avatar-video-generation/README.md) | Creates a lip-synced talking-head video from a person video and speech audio. It includes input validation, credit confirmation, task creation, status polling, and downloadable output handling. |
| [duix-avatar-conversation](duix-avatar-conversation/README.md) | Creates a real-time conversational digital human from a portrait, TTS voice, and optional persona settings, then returns a browser conversation link. |

## Getting Started

1. Choose a skill above and open its documentation.
2. Place that skill directory in your AI agent's skills directory.
3. Follow the skill-specific setup instructions, including `duix-cli` installation and credentials.

## Compatibility

Skills in this repository are designed for agent environments that support `SKILL.md`, including Codex, Cursor, Claude Code, Copilot, Gemini, and OpenClaw. Refer to each skill's README for its exact compatibility and prerequisites.
